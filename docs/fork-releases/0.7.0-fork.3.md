## What changed

- **Google AI Studio (Gemini) as a PDF converter.** Settings → PDF conversion → Google AI Studio (Gemini): paste a free AI Studio key (or let it use your Google model provider key), press Test, then Use for new PDFs. Gemini reads scanned pages, tables, formulas and diagrams, which the built-in reader cannot. The free tier has daily limits, and Google may use files sent on the free tier to improve its products, so don't upload private documents. Marked unverified until it has been tried with a real key; see docs/pdf-converters.md.
