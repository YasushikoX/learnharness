Third build of this fork: a reworked class page, a free online PDF reader (Google AI Studio), and quizzes and exams in the class that Short question can record, along with what you know. Everything in [build 2](https://github.com/YasushikoX/learnharness/releases/tag/v0.7.0-fork.2) is still here.

## What changed

- **Class page: files and settings on the side.** A class's files are listed in a side panel on the right with their pages and reading status. You add them with Add files, Camera, a pasted link, or by dropping them anywhere on the page. The Sources pop-up is gone. The same panel holds the skill map (language, Draft / Re-draft), exam, starting point, pace, lecture notes and Delete class…. The centre is for starting a session and your recent sessions. At 1024 px the panel opens from a button in the top bar.
- **New classes start with a short checklist:** name the class, then 1 add your class files (a large drop zone), 2 draft the skill map, 3 start learning. Each step ticks off when it is done, and nothing is shown disabled.
- **"Ask about this class" is now "Short question".** Learn and Practice only appear once they can start.
- **Google AI Studio (Gemini) as a PDF converter.** Settings → PDF conversion → Google AI Studio (Gemini): paste a free AI Studio key (or let it use your Google model provider key), press Test, then Use for new PDFs. Gemini reads scanned pages, tables, formulas and diagrams, which the built-in reader cannot. The free tier has daily limits, and Google may use files sent on the free tier to improve its products, so don't upload private documents. Marked unverified until it has been tried with a real key; see docs/pdf-converters.md.
- **Upcoming quizzes and exams.** The class side panel's exam-date field is now an Upcoming list: each quiz, exam, midterm, final or assignment with its date (and days left), what it covers and the skills it uses. Click one to edit it; + adds one. An exam date you set before shows as "Exam" and keeps working.
- **The class page follows the next one.** The countdown, readiness, the forecast, Today and the sidebar's days count down to the next dated quiz or exam. Its skills come first in Next up, and each skill's review is timed for the nearest quiz or exam that covers it.
- **Find in syllabus.** Reads the class files for the syllabus or schedule and lists every quiz and exam it finds, with the file, the page and the syllabus's own words for when it is. It takes a few model calls and stops after six; if it stops early it says so. Nothing is added until you press Add all (or drop or edit items first), and Add all adds everything or nothing. Dates are only taken when the words on the cited page state them; "Week 7, Friday" is worked out from the term's start date when the syllabus writes that date, otherwise the item has no date and keeps the syllabus's words. Running it again does not duplicate anything, your own edits win, and a quiz you deleted or renamed is never brought back by an older suggestion. When a file you add looks like a syllabus, the panel suggests it once.
- **Short question can change the class.** Say "quiz 3 is Friday next week and covers chapters 4 and 5" and it is saved straight away, with the date worked out from today in your time zone; "quiz 2 is cancelled" removes it. It asks only when it cannot tell which item you mean, a new one has no date, or the date could be two days ("next Friday" on a Wednesday: "Friday 27 Nov or Friday 4 Dec?"). Each change shows as a card with Undo. "Check the syllabus for exam dates" starts Find in syllabus.
- **"I know this" / "I don't get this".** Tell Short question what you already know or don't get, and it records it for those skills. Known: the skill counts as learned with a short check soon. Not sure: its review comes sooner. Don't get: it comes first in Next up, or back for review. The next practice result always overrides what you said. The skill shows "said: know" (with the date and Remove). It stays if you delete the conversation.

## Known limits

- The Gemini converter was written from Google's documentation and tested against a simulated API only.
- No real model has used the new Short question tools or run Find in syllabus yet; both were tested with scripted replies only.
- Dates use your browser's time zone, or the time zone of the computer the app runs on when the browser does not say.
- Everything listed under "Known limits" for build 2 still applies.
